✨  ANIMATIONS & EFFECTS
═════════════════════════════════════════════════════════════════════════════

Hover Effekte:
  • .card:hover           → transform: translateY(-5px), shadow++
  • .btn:hover            → transform: translateY(-2px), shadow++
  • .nav-links a:hover    → opacity: 0.8, border-bottom: 2px solid white
  • input:focus           → border: #667eea, box-shadow: rgba(...)

Keyframes:
  • @keyframes slideIn    → 0%: opacity 0, translateY(20px) → 100%: 1, 0
  • @keyframes fadeIn     → 0%: opacity 0 → 100%: opacity 1
  • @keyframes pulse      → scale animation

Transitions:
  • All: 0.3s ease
  • Buttons: 0.2s
  • Forms: 0.3s
