## 2. Interface Discovery

### Identify Your Network Interface

⚠️ **Important:** Interface naming varies (legacy `eth0` vs. modern `enp0s25`). Always verify first.

```bash
# List all interfaces
ip link show

# Look for primary Ethernet interface (LOWER_UP = active)
# Example output:
# 2: enp0s25: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
#     link/ether 90:1b:0e:5b:be:fd brd ff:ff:ff:ff:ff:ff
```

**Actions:**
- Note the interface name (e.g., `enp0s25`)
- Verify MAC address matches your provider's records
- Do NOT assume `eth0` (may not exist on modern Ubuntu)

## 4. Netplan Configuration

### File Locations

```bash
# Netplan config directory
ls -la /etc/netplan/

# Key files:
# - 01-network-manager-all.yaml     (global NetworkManager config)
# - 90-NM-*.yaml                    (auto-generated by NetworkManager)
# - 99-custom.yaml                  (user-defined, highest priority)
```

### Finding Existing Configs

```bash
# Check interface in existing Netplan files
sudo grep -r "enp0s25" /etc/netplan/

# Example output:
# /etc/netplan/90-NM-03b5f55d-3f6a-43d6-9991-196254104558.yaml:
#   match:
#     name: "enp0s25"
```

### Adding IPv6 Address

**Option A: Edit Existing Interface Config**

```bash
# Find the Netplan file for your interface
sudo nano /etc/netplan/90-NM-03b5f55d-3f6a-43d6-9991-196254104558.yaml

# Add IPv6 to the addresses list:
network:
  version: 2
  ethernets:
    NM-03b5f55d-3f6a-43d6-9991-196254104558:
      renderer: NetworkManager
      match:
        name: "enp0s25"
      addresses:
      - "2a01:4f9:c01f:e01b::1/64"      # ← Add this line
      dhcp4: true
```

**Option B: Create Custom Config**

```bash
# Create /etc/netplan/99-ipv6-custom.yaml
sudo tee /etc/netplan/99-ipv6-custom.yaml > /dev/null << 'EOF'
network:
  version: 2
  ethernets:
    enp0s25:
      addresses:
      - "2a01:4f9:c01f:e01b::1/64"
      routes:
      - to: "::/0"
        via: "fe80::1"           # IPv6 gateway (verify with your provider)
EOF
```

### File Permissions (Security)

⚠️ **Critical:** Netplan files should be readable only by root.

```bash
# Fix permissions on Netplan configs
sudo chmod 600 /etc/netplan/*.yaml

# Verify
ls -la /etc/netplan/
# Expected: -rw------- 1 root root

# Apply and test
sudo netplan apply
```

## 5. Verification & Validation

### 1. Apply Configuration

```bash
# Dry-run (shows changes without applying)
sudo netplan diff

# Apply changes
sudo netplan apply

# Check for errors
echo $?  # Should be 0 (success)
```

### 2. Verify IPv6 Address

```bash
# Show all IPv6 addresses on interface
ip -6 addr show dev enp0s25

# Expected output:
# inet6 2a01:4f9:c01f:e01b::1/64 scope global noprefixroute
#        valid_lft forever preferred_lft forever
```

**Key Status Indicators:**
- `scope global` = Globally routable ✅
- `noprefixroute` = Persistent (managed by Netplan) ✅
- `valid_lft forever` = No expiration ✅

### 3. Test Local Reachability

```bash
# Ping the IPv6 address locally
ping6 -c 3 2a01:4f9:c01f:e01b::1

# Expected: 3/3 packets, 0% loss
# Latency: < 1ms (local loopback)
```

### 4. Test External Connectivity

```bash
# Ping Google's IPv6 DNS
ping6 -c 3 2001:4860:4860::8888

# Expected: 3/3 packets, 0% loss
# If fails: Check gateway route (see Troubleshooting)
```

### 5. Verify DNS Resolution

```bash
# Forward lookup
dig +short AAAA example.com

# Reverse lookup (PTR)
dig -x 2a01:4f9:c01f:e01b::1 +short
# Expected: <your.hostname.com> (after Hetzner PTR setup)
```

## 6. Persistence Validation

### Confirm Configuration Survives Reboot

```bash
# Show current config
ip -6 addr show dev enp0s25

# Simulate reboot
sudo systemctl restart systemd-networkd

# Verify address still present
ip -6 addr show dev enp0s25

# Expected: Same IPv6 address, still present
```

### Automated Persistence Check

```bash
# Create a simple validation script
cat > /tmp/check_ipv6_persistence.sh << 'EOF'
#!/bin/bash
EXPECTED_IP="2a01:4f9:c01f:e01b::1"
CURRENT_IPS=$(ip -6 addr show dev enp0s25 | grep -oP '(?<=inet6\s)\S+' | cut -d/ -f1)

if echo "$CURRENT_IPS" | grep -q "$EXPECTED_IP"; then
    echo "✅ IPv6 persistent: $EXPECTED_IP present"
    exit 0
else
    echo "❌ IPv6 missing: Expected $EXPECTED_IP"
    echo "   Current: $CURRENT_IPS"
    exit 1
fi
EOF

chmod +x /tmp/check_ipv6_persistence.sh
/tmp/check_ipv6_persistence.sh
```

## 8. Troubleshooting

### Issue: IPv6 Address Not Showing

```bash
# Check Netplan syntax
sudo netplan --debug apply 2>&1 | grep -i error

# Verify file permissions
ls -l /etc/netplan/*.yaml

# Restart NetworkManager
sudo systemctl restart NetworkManager
sudo systemctl restart systemd-networkd

# Reapply
sudo netplan apply
```

### Issue: Cannot Ping IPv6

```bash
# Check routes
ip -6 route show

# Expected route to ::/0 (default gateway)
# If missing, add manually:
sudo ip -6 route add default via fe80::1 dev enp0s25

# Make permanent in Netplan
# Add to config:
# routes:
# - to: "::/0"
#   via: "fe80::1"
```

### Issue: "netplan apply" Returns Error

```bash
# Check syntax
sudo netplan validate

# Check for conflicting configs
grep -r "inet6\|ipv6" /etc/netplan/ | head -10

# Try removing 01-network-manager-all.yaml warnings
sudo chmod 600 /etc/netplan/01-network-manager-all.yaml
sudo netplan apply
```

### Issue: IPv6 Lost After Reboot

```bash
# Verify config file exists
cat /etc/netplan/90-NM-03b5f55d-3f6a-43d6-9991-196254104558.yaml | grep -A 3 addresses

# If addresses missing, re-edit and add:
# addresses:
# - "2a01:4f9:c01f:e01b::1/64"

# Reapply
sudo netplan apply

# Verify persistence
ip -6 addr show dev enp0s25
```

