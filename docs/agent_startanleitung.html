0) Pflicht: .env Setup (Vorlage)

Quelle: /home/danijel-jd/Dokumente/Workspace/Projekte/Gesamtprojekt/mcp_server/.env.example Hinweis: ops.sh liest PROJECT_ROOT/.env
Vorgehen: Kopiere die Vorlage ins Projekt-Root und setze Token/Keys. Ohne .env bricht ops.sh start ab. 
cd /home/danijel-jd/Dokumente/Workspace/Projekte/Gesamtprojekt

cp /home/danijel-jd/Dokumente/Workspace/Projekte/Gesamtprojekt/mcp_server/.env.example .env
nano .env

# Minimal-Check (Keys/Token)
grep -E '^(DASHBOARD_ADMIN_TOKEN|OPENAI_API_KEY_OPENA1|OPENAI_API_KEY_OPENA2)=' .env
Security: .env nicht committen. Secrets gehören in CI/CD Secret Store.

1) Quickstart (zentrale Steuerung)

# Projekt-Root
chmod +x bin/ops.sh

# Start: opena1, opena2, opena20 (Dashboard) + best-effort alle weiteren Agenten
bin/ops.sh start

# Health über alle Agenten
bin/ops.sh health

# Live Monitoring
bin/ops.sh monitor
