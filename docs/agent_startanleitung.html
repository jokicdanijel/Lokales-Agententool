ELION Hyper-Dashboard – Agenten Runbook (Local + Server)

Offline-fähiges Runbook (keine externen Assets). "Gestaltung" extern kommt durch Reverse Proxy Routing: /openaX/ → 127.0.0.1:PORT mit Prefix-Stripping.

0) ENV Setup (bindend)

Quelle: mcp_server/.env.example Wichtig: .env enthält Secrets 
cd PROJECT_ROOT

# Falls .env fehlt:
cp mcp_server/.env.example .env
nano .env

# Muss gesetzt sein:
# - DASHBOARD_ADMIN_TOKEN
# - OPENAI_API_KEY_OPENA1
# - OPENAI_API_KEY_OPENA2

1) Standard-Flow (Production)

cd PROJECT_ROOT

bin/ops.sh doc:agents
bin/ops.sh venv:sync opena4
bin/ops.sh start:agent opena4
curl -s http://127.0.0.1:12346/health | jq .

3) Per-Agent Workflow

# venv isolation + deps
bin/ops.sh venv:sync opena4

# Start einzelner Agent
bin/ops.sh start:agent opena4

# Health check
curl -s http://127.0.0.1:12346/health | jq .

# Logs
tail -n 200 logs/opena4.nohup.log

# Stop
bin/ops.sh stop:agent opena4
