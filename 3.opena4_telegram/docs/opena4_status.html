🎯 Rolle

Telegram Gateway Agent für Telegram ↔ PORTIER Kommunikation:

  • Telegram-Updates empfangen – Messages, Commands von autorisierten Usern
  • Option-2-Flow – Requests zu opena1 (kordp) weiterleiten
  • Antworten zurücksenden – Ergebnisse an Telegram-User pushen
  • Whitelisting – Nur autorisierte User (via ENV-Variable)

📡 API-Endpunkte

GET /health Health-Check mit Telegram-Status
GET / Agent-Info & Beschreibung
GET /status Service-Status mit Safepoints
POST /command Command-Endpoint (Bearer-Auth)
POST /telegram/message Telegram-Nachricht empfangen (Webhook)
POST /github/webhook GitHub CI/CD Notifications

💬 Telegram Bot-Befehle

  • /start – Willkommen & Übersicht
  • /browse <url> – URL analysieren via opena6 (Browser)
  • /analyze <file> – Datei analysieren
  • /status – Service-Status anzeigen
  • /help – Hilfe anzeigen

Normale Nachrichten werden automatisch über den Option-2-Flow weitergeleitet.

🔐 Security & Compliance

  • ✅ User-Whitelisting: Nur autorisierte Telegram-IDs via TELEGRAM_ALLOWED_USER_IDS
  • ✅ Bearer-Token: Für HTTP-Endpoints (außer /health)
  • ✅ Secret-Masking: Tokens werden in Logs/Safepoints maskiert
  • ✅ ENV-only Secrets: Keine Tokens im Code
  • ✅ Port-Policy: Port 12346 in PORTIER-Range (12344-12399)

🔧 ENV-Variablen
