opena6 – Developer Overview

Technische Dokumentation für Browser Automation Agent | PORTIER 3.0

🏗️ Architektur

5.opena6_browser/
├── main_browser_agent.py     # FastAPI Entry Point (Port 12350) ✅
├── config.py                 # Pydantic V2 Config ✅
├── models.py                 # Pydantic Request/Response Schemas ✅
├── tests/                    # Pytest-Suite
│   └── test_opena6_api.py
├── bin/
│   └── start_opena6.sh       # PID-basiertes Start-Skript
├── docs/                     # HTML-Dokumentation ✅
├── logs/                     # Nohup-Logs
└── data/screenshots/         # Screenshot-Speicher ✅

Hauptkomponenten

  • FastAPI-Service auf Port 12350 – uvicorn mit Lifespan
  • Browser-Engine: Playwright (chromium/firefox/webkit konfigurierbar)
  • Headless-Mode: Default true, via BROWSER_HEADLESS
  • Pool-Management: MAX_PARALLEL_BROWSERS (Default: 3)
  • Auth: Bearer Token Middleware (verify_token)
  • Safepoints: Automatische Archivierung aller CMD/RESP mit Secret-Masking

⚙️ Konfiguration (ENV-Variablen)

# Core Settings
OPENA6_PORT=12350              # Service Port
BEARER_TOKEN=            # Auth Token (PFLICHT!)

# Browser Engine
BROWSER_TYPE=chromium          # chromium, firefox, webkit
BROWSER_HEADLESS=true          # Headless-Mode
BROWSER_USER_AGENT=""          # Custom User-Agent (optional)
BROWSER_TIMEOUT=30000          # Default Timeout in ms

# Pool & Limits
MAX_PARALLEL_BROWSERS=3        # Max parallele Sessions

# Storage
SCREENSHOT_DIR=data/screenshots
ARCHIVP_ROOT=../1.opena1&2_portier/archivp_store

Pydantic V2 Config

  • ServiceConfig(BaseSettings) mit SettingsConfigDict
  • AgentInfo mit model_config = ConfigDict(extra="forbid")
  • Alle Schemas in models.py sind V2-konform

Safepoint-Strategie

  • CMD: Navigate/Extract/Screenshot Requests (URL, Selektoren)
  • RESP: Status, Pfad/URL, Ergebnis-Preview
  • Screenshots: Nur Pfad im Safepoint, Bild extern gespeichert
  • Secret-Masking: URLs mit Tokens/API-Keys werden maskiert

🔐 Security & Compliance

  • Rate-Limiting pro Ziel-Domain: Max. 10 Requests/Minute
  • robots.txt respektieren: Automatische Prüfung vor Navigation
  • Keine Massen-Scraping-Jobs: Nur mit explizitem Opt-In
  • User-Agent: Korrekt als Bot identifiziert
  • Auth: Bearer Token für alle Endpoints
  • CAPTCHA-Handling: Keine automatische Umgehung

💻 cURL-Beispiele

Health-Check (ohne Auth)

curl -s http://127.0.0.1:12350/health | jq .

Agent-Info (ohne Auth)

curl -s http://127.0.0.1:12350/ | jq .

Navigate (mit Bearer Token)

curl -s -X POST http://127.0.0.1:12350/navigate \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "wait_until": "load",
    "timeout": 30000
  }' | jq .

Screenshot

curl -s -X POST http://127.0.0.1:12350/screenshot \
  -H "Authorization: Bearer $BEARER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "full_page": true,
    "format": "png"
  }' | jq '.path, .size_bytes'

Extract (CSS-Selektoren)

curl -s -X POST http://127.0.0.1:12350/extract \

Click

  -H "Content-Type: application/json" \

🔐 Security-Hinweise

Bearer-Token-Handling

  • ENV-Only: Bearer-Token ausschließlich via BEARER_TOKEN Umgebungsvariable
  • Keine Hardcodes: Niemals Tokens in Code oder Config-Dateien
  • .env-Datei: Muss in .gitignore stehen
  • Token-Rotation: Regelmäßig neue UUIDs generieren

Browser-Spezifische Sicherheit

  • Headless-Mode: Standardmäßig aktiviert (keine GUI-Exposition)
  • User-Agent: Als Bot identifiziert (keine Täuschung)
  • robots.txt: Respektieren (konfigurierbar)
  • Rate-Limiting: Max. 10 Requests/Domain/Minute
  • Keine CAPTCHA-Umgehung: Automatische Umgehung verboten

Secret-Masking in Safepoints

  • Automatisch maskiert: token, password, secret, key, bearer, auth
  • URLs mit Tokens: Query-Parameter werden maskiert (?token=***)
  • Screenshots: Nur Pfad im Safepoint, Bild extern gespeichert
  • Base64: Aus Safepoints entfernt (zu groß)

Port-Policy (PORTIER 3.0)

  • Erlaubter Bereich: 12344–12399
  • Verbotene Ports: 8080 (reserviert für OpenWebUI UI)
  • Enforcement: Service startet nicht bei ungültigem Port
