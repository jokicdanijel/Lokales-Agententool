🎯 Rolle

Browser Automation Agent für automatisierte Web-Interaktionen:

  • Navigate – URLs öffnen, Seiten laden
  • Extract – Daten mit CSS-Selektoren extrahieren
  • Screenshot – Bildschirmfotos erstellen
  • Click – Elemente klicken
  • Form-Fill – Formulare ausfüllen

📡 API-Endpunkte

GET /health Health-Check mit Browser-Status
GET / Agent-Info & Capabilities
POST /navigate URL öffnen (wait_until, timeout)
POST /screenshot Screenshot erstellen (full_page, selector, base64)
POST /extract Daten mit CSS-Selektoren extrahieren
POST /click Element klicken (wait_after)
POST /form/fill Formular ausfüllen (submit_selector)
POST /command Option-2-Flow generischer Command

🔗 Integration

  • Kürzel: browsep (Tool-Registry)

  • Orchestrierung: opena1 (kordp) koordiniert Browser-Flows
  • Terminal-Agent: opena3 (owuip) für Web-LLM-Zugriff

🛠️ Technologie-Stack

  • Framework: FastAPI + uvicorn
  • Browser-Engine: Playwright (chromium/firefox/webkit konfigurierbar)
  • Headless-Mode: Ja (Default, konfigurierbar via BROWSER_HEADLESS)
  • Pool-Management: Max. MAX_PARALLEL_BROWSERS parallele Sessions
  • User-Agent: Konfigurierbar via BROWSER_USER_AGENT
  • Pydantic V2: model_config = ConfigDict(extra="forbid")
  • Safepoints: YYYY/MM/DD Format mit Unicode-Pfeil →
