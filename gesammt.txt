2) BotFather & Telegram‑Basics
2.1 Bot erstellen
    • In Telegram: Suche @BotFather.
    • Sende /newbot → gib Name + Benutzername (endet üblicherweise auf bot) ein.
    • Kopiere den API‑Token (z. B. 123456:ABCDEF…) → trage ihn in .env ein:
      TELEGRAM_BOT_TOKEN=123456:ABCDEF...
      TELEGRAM_WEBHOOK_SECRET=<mindestens 16 zeichen>

    • Optional: /setdescription, /setabouttext, /setcommands (z. B. start, health, start_agent, stop_agent), /setprivacy (z. B. private Nachrichten)
2.2 Webhook vs. Long‑Polling
    • Long‑Polling: Einfacher Setup, Bot fragt Telegram regelmäßig ab (getUpdates).
    • Webhook (empfohlen für Produktion): Telegram sendet Updates an deinen HTTPS‑Endpoint. Vorteil: Echtzeit, effizienter. (Telegram)
    • Voraussetzungen laut Telegram: HTTPS mit TLS1.2+, öffentlicher Port (443, 80, 88 oder 8443) oder via Reverse Proxy. (Telegram)
2.3 Webhook setzen
Zum Beispiel mit curl:
curl -X POST "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook" \
     -d "url=https://dein.host/telegram/webhook&secret_token=<WEBHOOK_SECRET>"
Antwort sollte etwa sein: {"ok":true,"result":true,"description":"Webhook was set"} (Stack Overflow)

🛠 Schritt 5 — opena5 · VS Code‑Bridge
Projektwurzel (Pflicht): /home/danijel‑jd/Dokumente/projekte/Gesammtprojekt
Ports: erlaubter Pool 12344–12399 · Port 8080 bleibt ausschließlich für OpenWebUI (opena3) (Loopback).
Modell: gpt‑5‑nano · Strict Mode: true · Regeln: Append‑only · Dedupe (SHA‑256/IDs) · Keine Doppelblobs · Auditierbar.

0) Zweck & Rolle
„opena5“ verbindet deinen Quellcode‑Editor (VS Code) mit deinem Agent‐System‑Stack. Zweck: Änderungen, Diffs, Edit‐Aufgaben, Codeaktionen, die über den Chat, das UI oder Monitoring angestoßen wurden, gelangen ins VS Code‑Workspace und werden dort bearbeitet. Danach geht’s weiter ins Archiv („opena2“) und dann ggf. zur Ausführung („opena1“) etc.
Kurz:
    • Eingang: EDIT/DIFF Aufgaben (z. B. Codeänderung angelegt via UI oder Bot)
    • Verarbeitung: VS Code öffnet Workspace, zeigt die Änderung, ggf. Commit, Push
    • Rückmeldung: Status/Bestätigung in Archiv + UI sichtbar gemacht

1) Topologie & Verbindungen
┌──────────┐    (Edit‑Aufgabe)     ┌──────────┐
│  opena3  │ ───────────────────▶ │  opena5  │
│  (UI)    │                        │  (VSCode)│
└──────────┘                        └────┬─────┘
                                         │  Änderung fertig
                                         ▼
                                   ┌──────────┐

                                   └──────────┘

                                         ▼
                                   ┌──────────┐
                                   │  opena1  │ (Koordinator)
                                   └──────────┘
Alle Aktionen laufen über opena2 als Wahrheit („Archivator“) und opena1 als Ausführungssteuerung. VS Code (opena5) ist Teil des Rückflusses: erhält Aufgaben, macht Änderungen, spielt zurück.

2) Port‐ & Bindings‐Politik
    • opena5 bindet typischerweise einen internen API‑Port im erlaubten Bereich z. B. 12348.
    • Keine Bindung auf Port 8080 erlaubt (dies bleibt ausschließlich opena3).
    • Änderungen durch VS Code (z. B. über eine Extension oder CLI Hook) dürfen nicht außerhalb des Pools arbeiten.
    • In .runtime/port_leases.json wird eingetragen:
      {
        "leases":[
          {"agent":"opena5","port":12348,"ts":"2025-10‑22T12:00:00Z","state":"ide‑bridge"}
        ],
        "pool":"12344‑12399"
      }

3) Aufgaben, Aktionen & Persistenz
3.1 Aufgaben kommen rein
Wenn z. B. über UI (opena3) oder Bot (opena4) eine Edit/DIFF Aufgabe generiert wird:
    • Eventtyp: EDIT_TASK
    • Dedup‑Key: file_path + sha256(diff_contents)
    • Persistenz: archivp/.../patches/src/{file_path}/{sha256(diff)}.json (append only)
    • Audit‑Eintrag: archivp/index.jsonl mit Zeitstempel, Actor=open­a3/opena4, Event=EDIT_TASK
3.2 VS Code Bridge nimmt entgegen
    • VS Code (opena5) holt sich die Aufgabe (z. B. via local API Port 12348 /tasks/poll)
    • Öffnet das angegebene file_path im Workspace, zeigt Diff/Anweisung
    • Entwickler übernimmt: ändert Code, speichert, ggf. commit & push (oder automatisiert)
    • Nach Abschluss schreibt opena5:
        ◦ Safepoint CMD: SP<ts>_opena5→opena2_CMD.json mit Payload { file_path, diff_sha256, author }
        ◦ Persistenz der Änderung: ggf. blobs/patches/src/...
    • opena2 schreibt RESP: SP<ts>_opena2→opena5_RESP.json mit Ergebnis (status: ok/failed, details)
    • Audit‑Index ebenfalls ergänzt

class CommandIn(BaseModel):
    request_id: str = Field(min_length=8)
    action: str = Field(pattern=r"^(start|stop|restart|ping|flush_cache)$")
    strict: bool = True

@app.post("/api/command/{agent}")
async def api_command(agent: str, request: Request, _: None = Depends(require_admin_token)) -> JSONResponse:
    payload = await parse_form_or_json(request)
    try:
        cmd = CommandIn(**payload)
    except Exception as e:
        # Safepoint (Validation Error) – kein Dispatch
        sp = write_sp(src="opena19", dst="opena1", kind="CMD", body={"error":"validation","detail":str(e),"agent":agent,"payload":payload})
        bus.publish("sp_created", {"sp": sp})
        raise HTTPException(422, "Schema ungültig")

    # Policy: Port 8080 verboten (global)
    if 8080 in FORBIDDEN_PORTS:
        pass  # policy tracked via health only; enforcement erfolgt bei Diensten

    # Safepoint: Dashboard fordert Action an
    sp_cmd = write_sp(src="opena19", dst="opena1", kind="CMD", body={"agent":agent,"action":cmd.action,"request_id":cmd.request_id,"strict":True})
    bus.publish("sp_created", {"sp": sp_cmd})

    # Simulierter Orchestrierungs-Trigger (Koordinator übernimmt in realem Setup)
    # Für "ping": wir prüfen Agent-Health und antworten direkt.
    if cmd.action == "ping":
        st = list_agents_status(REG, [agent])[0] if REG.get_agent(agent) else {"health":"down"}
        sp_resp = write_sp(src=agent, dst="opena2", kind="RESP", body={"agent":agent,"action":"ping","result":st.get("health","down"),"strict":True})
        bus.publish("sp_created", {"sp": sp_resp})
        return JSONResponse({"strict": True, "status": "ok", "result": st})

    # Für start/stop/restart/flush_cache: Wir quittieren Annahme (202)
    return JSONResponse({"strict": True, "status": "accepted", "info": {"agent": agent, "action": cmd.action}}, status_code=202)

def _admin_token() -> str:
    # Token aus .env (oder Prozessumgebung) laden
    token = os.environ.get("DASHBOARD_ADMIN_TOKEN", "")
    if not token:
        # optional: aus Datei laden, wenn exportiert
        env_path = os.path.join(BASE_DIR, "19.dashboard_agent", ".env")
        if os.path.exists(env_path):
            for line in open(env_path, "r", encoding="utf-8"):
                if line.startswith("DASHBOARD_ADMIN_TOKEN="):
                    token = line.strip().split("=",1)[1]
                    break
    return token

def require_admin_token(request: Request):
    auth = request.headers.get("Authorization","")
    if not auth.startswith("Bearer "):
        raise HTTPException(401, "Authorization fehlt")
    token = auth.split(" ",1)[1].strip()
    if token != _admin_token() or not token:
        raise HTTPException(403, "Token ungültig")
    return None

async def parse_form_or_json(request: Request) -> Dict[str, Any]:
    ctype = request.headers.get("content-type","").lower()
    if "application/json" in ctype:
        return await request.json()
    if "application/x-www-form-urlencoded" in ctype:
        form = await request.form()
        data = {k: (v if k!="strict" else (str(v).lower()=="true")) for k,v in form.items()}
        return data
    # Fallback: versuche JSON
    try:
        return await request.json()
    except Exception:
        raise HTTPException(400, "Unsupported Content-Type")

class AgentRegistry:

from __future__ import annotations
import os, json, time, hashlib, psutil
from datetime import datetime, timezone
from pathlib import Path
from typing import Any, Dict, List, Optional

BASE_DIR = "/home/danijel-jd/Dokumente/Workspace/Projekte/Gesamtprojekt"
ARCHIVP = Path(BASE_DIR) / "1.portier_openai" / "archivp"
INDEX = ARCHIVP / "index.jsonl"

def _ensure_daydir(ts: float) -> Path:
    d = datetime.fromtimestamp(ts, tz=timezone.utc).astimezone()
    day = ARCHIVP / f"{d:%Y/%m/%d}"
    day.mkdir(parents=True, exist_ok=True)
    return day

def write_sp(src: str, dst: str, kind: str, body: Dict[str, Any]) -> str:
    assert kind in ("CMD","RESP")
    ts = time.time()
    day = _ensure_daydir(ts)
    name = f"SP{int(ts)}_{src}→{dst}_{kind}.json"
    p = day / name
    body_out = {
        "ts": datetime.fromtimestamp(ts, tz=timezone.utc).astimezone().isoformat(),
        "src": src, "dst": dst, "kind": kind, "strict": True, "body": body
    }
    txt = json.dumps(body_out, ensure_ascii=False, indent=2)
    p.write_text(txt, encoding="utf-8")
    # Index append-only
    INDEX.parent.mkdir(parents=True, exist_ok=True)
    with INDEX.open("a", encoding="utf-8") as f:
        f.write(json.dumps({"sp": name, "ts": body_out["ts"], "src": src, "dst": dst, "kind": kind, "path": str(p), "strict": True}, ensure_ascii=False) + "\n")
    return str(p)

def query_sp(filters: Dict[str, Any], limit: int) -> List[Dict[str, Any]]:
    res=[]
    date_from = filters.get("date_from")
    date_to   = filters.get("date_to")
    srcs = set(filters.get("src", []))
    dsts = set(filters.get("dst", []))
    kinds= set(filters.get("kind", []))
    # effizient: index.jsonl filtern
    if not INDEX.exists(): return []
    with INDEX.open("r", encoding="utf-8") as f:
        for line in reversed(list(f)):  # reverse: neuste zuerst
            try:
                obj = json.loads(line)
            except Exception:
                continue
            ts = obj.get("ts","")[:10]  # YYYY-MM-DD
            if date_from and ts < date_from: continue
            if date_to and ts > date_to: continue
            if srcs and obj.get("src") not in srcs: continue
            if dsts and obj.get("dst") not in dsts: continue
            if kinds and obj.get("kind") not in kinds: continue
            res.append(obj)
            if len(res) >= limit: break
    return res

def list_agents_status(reg) -> List[Dict[str, Any]]:
    out=[]
    for meta in reg.list_agents():
        name = meta["name"]
        port = reg.port_for(name)
        health = "down"
        last_seen = ""
        try:
            if port >= 12344 and port <= 12399:
                # einfacher TCP-Healthcheck via HTTP HEAD (timeout kurz)
                import http.client
                conn = http.client.HTTPConnection("127.0.0.1", port, timeout=0.3)
                conn.request("GET", "/health")
                r = conn.getresponse()
                health = "healthy" if r.status == 200 else "degraded"
                conn.close()
        except Exception:
            health = "down"
        # Systemressourcen (lokal – optional)
        cpu = f"{psutil.cpu_percent(interval=None)}%"
        ram = f"{round(psutil.virtual_memory().percent,1)}%"
        out.append({
            "name": name, "role": meta["role"], "path": meta["path"],
            "port": port, "health": health, "last_seen": last_seen,
            "uptime": "n/a", "cpu": cpu, "ram": ram
        })
    return out

from __future__ import annotations
import queue
from typing import Iterator, Dict, Any

class EventBus:
    def __init__(self) -> None:
        self.q: "queue.Queue[Dict[str,Any]]" = queue.Queue()

    def publish(self, ev_type: str, data: Dict[str,Any]) -> None:
        self.q.put({"type": ev_type, "data": data})

    def subscribe(self) -> Iterator[Dict[str,Any]]:
        while True:
            yield self.q.get()

from pathlib import Path
import json, hashlib
base = Path("/home/danijel-jd/Dokumente/Workspace/Projekte/Gesamtprojekt/1.portier_openai/archivp")
docs = base.parent / "docs"
target = docs / "INTEGRITY_TREE.json"
tree = {}
for sp in base.rglob("SP*.json"):
    day = sp.relative_to(base).parts[0:3]
    key = "-".join(day)
    h = hashlib.sha256(sp.read_bytes()).hexdigest()
    tree.setdefault(key, {"entries":{}})["entries"][sp.name] = h
for d in tree.values():
    concat = "".join(sorted(d["entries"].values()))
    d["root_hash"] = hashlib.sha256(concat.encode()).hexdigest()
target.write_text(json.dumps(tree, indent=2, ensure_ascii=False), encoding="utf-8")
print(f"Integritätsbaum aktualisiert: {target}")
